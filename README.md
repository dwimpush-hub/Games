## 🕹️ Games Included

### **1. Wizard Chess**

A reimagined, spell-slinging, chaos-infused version of classic chess.

#### **Core Features**

* Chaos Events always enabled
* Unique spells for each court piece
* AI opponent with timed movement and animated highlights
* Hint system showing golden move tiles and full piece names
* Pawn promotion to highest-tier piece
* Responsive UI (arcade-style for desktop, simplified on mobile)
* Save/Load (coming soon)
* Animated intro (coming soon)

#### **Rules Summary**

* Standard chess movement applies unless modified by spells or chaos effects.
* Chaos events do **not** skip turns.
* Hint system highlights all valid moves and uses full-piece names.
* Spell usage is optional.
